## 専用キャンバス

初期本文は全角空白だけにします。罫線を描くと一太郎が本文の文字や空白配置を変えるため、通常の文字範囲レシピと併用できません。初期本文の非空白文字は実行前に拒否し、セル文字は表を作成した後の `tableText` 操作で設定します。

`keisenCanvas: {"rows":7,"columns":13}` は1ページ目の観測範囲です。座標は1始まり、列は半角単位、行は通常位置です。mm座標ではありません。本文は行数を一致させ、各行に列数の半分を切り上げた個数以上の全角空白を配置します。キャンバス・操作数の上限は入力validatorで検査します。線の外側に少なくとも1点の観測余白を残します。

## 操作

### セル内の文字

内部Recipeの `tableText` は1始まりの `cell.row` / `cell.column` で対象を指定し、文字を設定・置換します。空文字 `""` は消去です。既存セルを範囲選択して `EraseKeisenCell` を呼び、通常編集モードでセルへ移動し直して `Insert` します。

```json
{"type":"tableText","cell":{"row":1,"column":2},"text":"甲"}
```

長文・改行・空白・結合文字・サロゲートを含む文字列は対象外です。自動折り返しによる表の移動を避けるため、セル幅から余裕を引いた短い文字数だけを受け付けます。正確な上限と公開区分は内部validatorと[パラメータ対応表](generated/parameter-exposure.md)を参照してください。構造変更は文字の設定より前に行います。文字入りセルを保ったままの行列操作・結合・分割は未対応です。

文字を扱う試料では、各操作後・保存前・再読込後に全セルを範囲選択し `GetString(2)` で文字列を取得します。対象セルの完全一致と他セルの保持、罫線グリッドとセル属性の保持を要求します。getterが複数要素を返す場合も、曖昧に連結せず失敗にします。検証証跡は `version:3` / `textVerified:true` で、文字を観測しない空表のversion 2とは区別します。

文書全体の読み戻しから空白を除いた文字列も、全セルの行優先順の文字列と比較して余分な非空白文字を検出します。セル内文字は完全一致ですが、本文全体の空白配置は保証しません。外部Sample Catalogは空表の契約を維持し、文字入りセルは内部Recipeのみで利用できます。

### 本文の線分

```json
{"type":"line","mode":"draw","from":{"row":3,"column":3},"to":{"row":3,"column":11},"lineType":1,"color":"R0G0B0"}
```

水平・垂直線を描画できます。`change` は `KeisenChange` による線種・色変更、`clear` は解除です。解除時は `lineType` / `color` を省略します。線種は1〜15、色は各成分0〜255のRGB文字列です。複数の線で交差を作れます。

```json
{"type":"table","rows":[2,4,6],"columns":[3,7,11],"lineType":1,"color":"R0G0B0"}
```

罫線の境界を列挙し、外枠から最大2×2セルまで作成します。行境界は2以上、列境界は4以上の間隔を空け、列境界は奇数にします。1試料に表は1個です。独立した線の操作との混在は拒否します。

```json
{"type":"tableAttribute","attribute":"fill","value":50}
```

表作成後、**表全体**に1属性ずつ設定します。属性は `alignment`（1/2/3/10）、`textColor`（RGB）、`bold` / `italic`（0/1）、`fill`（0〜107）、`color`（飾り色RGB）です。塗りつぶし解除は `fill:0` です。`cell: {"row":1,"column":2}` を指定すると、表内の1始まりの行・列番号で単一セルへ適用します。省略時は表全体です。複数セルは操作を分けて指定します。行高・列幅は後述の `tableResize` で変更できます。セル数は後述の等分割・内部境界の解除でも変更できます。任意位置へのセル挿入、任意のセルだけの結合、任意の罫線変更は未対応です。

```json
{"type":"tableAttribute","cell":{"row":1,"column":2},"attribute":"fill","value":50}
```

## 検証の意味

- 初期・各操作後・保存前・再読込後に、観測範囲の全点で `GetPieceOfKeisen` の8方向の線種・線色・背景色と4方向の面取りを取得します。
- 要求した線の両端と接続を照合し、範囲内の対象外の線・属性が変化していないことも検査します。消した線の残留色は解除直後の期待値照合から除外し、保存前後では一致を要求します。
- 表属性は通常編集モードで対象行の先頭から `RightCell` で移動したセル内の代表点で `GetKeisenAttribute` の6項目を取得し、要求属性と未変更属性を照合します。単一セル指定では他の全セル代表点の6属性も保持を確認します。`GetRange` のページ・セル単位を検査し、始点・終点座標を証跡に記録します。座標値の記録と、対象・対象外セルの属性照合を区別します。セル内部の全位置を調べた保証ではありません。
- 空表の本文は `bodyComparison: "blank-canvas-whitespace-only"` と記録します。文字入り表は `cell-text-exact-and-body-nonwhitespace` です。空白の個数・位置は保持を要求しません。通常の文字レシピの本文完全一致検査は維持します。
- `keisenProof.version` は空表では2、セル文字を観測する試料では3です。`cellGetterMode: "normal-editing"` とともに読み戻し方式、操作ごとの成否・検証範囲・制限を保存します。指定グリッド外の罫線、画面での形状、mm単位の寸法は未検証です。

バイナリ差分は本文の空白変化にも影響されます。罫線getterと相関しても罫線専用フィールドと断定できません。同条件再保存の `control` を比較基準にして、レポートの観測値と制限を併せて確認してください。次の試料レシピは比較基準の設定・罫線操作・セル指定を引き継ぎ、基準条件を2回、異なる1条件を2回再作成します。空白だけの対照に置き換えません。罫線固有の境界値探索はまだ自動化していません。

## 行高・列幅の変更（v0.11）

```json
{"type":"tableResize","axis":"row","index":1,"delta":1}
```

`KeisenModifyLineMode/Start/End` と `KeisenModifyLine`、列側の対応マクロを使い、既存の表の内側へ空間を挿入・削除します。`index` は表内の1始まりの行・列番号、`axis` は `row` または `column` です。正の `delta` は拡大、負は縮小です。行は物理行単位で±1〜3、列は半角桁単位で±2または±4を指定します。mm指定ではありません。

セル数は変わりません。例えば行境界 `[2,4,6]` の第1行を `delta:1` にすると `[2,5,7]` になります。操作ごとの境界を更新し、新旧の線の位置・消去・接続と全セルの属性を照合します。行高2、列幅4以上を維持し、移動後も観測範囲内に1点の余白が必要です。寸法変更は表属性の設定より先に行ってください。変更後のセル属性設定は可能です。

コピー挿入は、単純なセル追加と異なる罫線形状を観測したため公開していません。`examples/keisen-table-resize.json` で拡大・元の寸法への復元・第2行/列・変更後のセル設定を試験できます。

## 行・列の分割と結合（v0.12）

```json
{"type":"tableDivide","axis":"row","parts":2}
{"type":"tableMerge","axis":"row","boundary":1}
```

`tableDivide` は未分割の軸を2等分します。`axis` は `row` または `column`。行は `KeisenLineDivide` / `KeisenLineDivideEqually`、列は対応するColumnマクロを使い、`Keisen` で確定します。外枠の寸法は変えず、最大2×2セルです。行・列の順序を入れ替えても実行できます。整数位置で等分でき、各セルが行高2・列幅4以上で、列境界が全角位置（奇数）になる必要があります。

`tableMerge` はその軸にある唯一の内部境界（`boundary:1`）を `Keisen(0)` で取り除きます。行境界なら全列にわたって上下セルを、列境界なら全行にわたって左右セルを結合します。外枠は解除しません。1セルだけを選んで結合する機能ではありません。

分割・結合も表属性の設定前に限ります。変更後に新しいセルへ属性を設定することは可能です。新旧セルの重なりを `cellLineage` に記録し、分割後の各セルや結合後のセルが、対応する変更前の全セルの6属性を保持していることを要求します。結合元の属性が異なる場合は成功扱いにしません。`cellLineage` のキーはgetter証跡と同じ0始まりの「行-列」、レシピの `cell.row` / `cell.column` は1始まりです。

この機能は外枠内の境界を増減します。新しい領域を挿入して外枠も大きくする行・列の追加や、コピー挿入とは別です。

分割・結合を繰り返して同じgetter値へ戻っても、JTD内部の操作履歴や残存レコードは同じとは限りません。現在の相関解析は観測値が同じ試料をまとめるため、履歴差のバイトが反復内変動として候補から除外される場合があります。自動生成された同一レシピの反復を実行して、同じ操作履歴での変動と区別してください。

## 作成済みの表境界の線種・線色を変える

内部Recipeの `tableRule` は、既存の表境界を端から端まで選び、`KeisenChange` で線種と線色を変更します。セルを選ぶ操作ではありません。`axis: "row"` は横線、`axis: "column"` は縦線を意味し、`boundary` は現在の表の境界配列を0始まりで参照します。最初と最後の境界は外枠、それ以外は内部罫線です。セル指定の1始まりとは異なります。

```json
{"type":"tableRule","axis":"row","boundary":1,"lineType":3,"color":"R0G0B255"}
```

この例は2行の表の内部横線を変更します。元の線種・線色を再指定すれば復元でき、その後の再設定も可能です。線を削除する操作ではないため、セル数は変わりません。寸法変更や分割・結合を先に行った場合は、変更後の境界位置を使います。従来のtableResize/tableDivide/tableMergeでは、境界の線種が混在した後の構造変更は未対応のため、tableRuleより先に置きます。セル属性の設定はtableRuleの前後で行えます。以下の局所構造操作は別の実行経路で境界ごとの線種・色を追跡します。

検証は選択線分の両端・交点を含む全観測グリッドと全セルの属性getterを比較します。指定外の境界、交点の別方向の線、セル属性が変われば失敗にします。保存・再読込でも同じ状態を要求します。証跡には境界番号と、その時点で解決した線分座標を残します。

この操作履歴は内部Recipeだけで扱います。外部Sample Catalogの表全体の線種・線色指定とは区別し、境界ごとの最終状態指定はまだ公開していません。公開方針は[生成対応表](generated/parameter-exposure.md)を参照してください。

## 文字入り表の行列操作と局所的な結合・分割

内部Recipeの `tableBand` は行・列を追加または削除します。`index` は現在の境界配列で区切られた帯の1始まり番号です。追加は指定帯の直前に空の帯を作り、最後の帯の次を指定すると末尾追加になります。`size` を省略すると対象帯（末尾追加なら最後の帯）と同じ寸法です。行は通常行座標、列は半角桁座標を使います。削除は指定帯の文字も削除し、それ以外の文字を移動します。

```json
{"type":"tableBand","axis":"row","mode":"insert","index":2}
{"type":"tableBand","axis":"column","mode":"delete","index":1}
{"type":"cellMerge","from":{"row":1,"column":1},"to":{"row":2,"column":1}}
{"type":"cellSplit","cell":{"row":1,"column":1},"rows":2,"columns":1}
```

`cellMerge` は両端を含む矩形内の完全なセルを結合します。既存の結合セルを途中で切る指定は拒否します。`cellSplit` は指定セルだけを等分し、隣接セルを保持します。セルの指定は現在の境界配列で区切られた位置の1始まり番号です。結合セルに含まれるどの位置でも、その結合セルを指します。分割で新たな境界座標が加わると、後続操作の番号も変わります。証跡には操作ごとの幾何、安定したセルID、新旧セルの対応を残します。

文字は結合時にも元の物理位置を保ちます。分割線が既存文字を横切る入力は拒否します。結合セルを横切る帯の追加ではセルを延長し、削除では短縮します。既存の罫線の線種・色は移動後も保持し、新しく必要な罫線には最初のtableの指定を使います。構造変更経路のtableRuleは、指定境界に実在する線分だけを変更します。

読み戻しでは、全観測グリッドの8方向の罫線、全セルの属性、空行を含む物理行ごとの文字を確認します。セル属性の異なる親セルを結合すると、親属性をすべて保持できたとは判定しません。混在する文字書式の位置別検証は対象外です。設定値・制限・公開判断の正本は[生成Capability表](generated/sample-capabilities.md)と[パラメータ対応表](generated/parameter-exposure.md)です。

この操作履歴は内部Recipeで使います。従来のtableResize/tableDivide/tableMergeとの混在はできません。実行例は[境界位置の行列操作](../examples/keisen-band-boundaries.json)、[局所結合・再分割](../examples/keisen-local-cells.json)、[結合セルをまたぐ操作](../examples/keisen-spanning-cells.json)、[寸法指定と右下セルの分割](../examples/keisen-custom-structure.json)を参照してください。[開発・実機記録](maintainer/table-structure-development.md)には失敗時の発見も残しています。

### 外部要求の線種・線色省略（2026-10-13）

Sample Catalogの表で線種・線色を省略した場合は、一太郎の現在の設定値を利用する。コンパイラは内部のtable操作に `null` を保持し、Keisen呼出しの該当引数を空にする。明示した値の照合に加え、全罫線の存在・範囲外・保存再読込後の観測値保持を検査する。省略属性を任意の固定値と一致したとは扱わない。背景色扱いの罫線など検証条件を満たさない場合は成功扱いにしない。

内部Recipeの従来の線種・色の明示指定は変わらない。自動属性の表と寸法・トポロジ変更履歴の組合せは未対応として拒否する。外部の空表・セル属性は対応範囲。外部JSONの `null` 直接指定は受け付けない。

## 外部要求の表の拡張（APP-12、2026-10-15）

Sample Catalogの `keisen-table` は最終状態として、最大4×4の行列数、`rowHeights`（通常行単位）、`columnWidths`（半角単位の偶数）、重ならない `merges`、セルの `text` を受け付ける。コンパイラは境界配列を行2・列3から寸法を積み上げて作り、観測キャンバスを表の外側1点の余白を残す大きさに決める（行は合計9、列は合計18まで）。結合は `cellMerge`、文字は結合後に `tableText`、属性はその後に安定した順序で並べる。結合セルは左上の位置だけで指定でき、内側の位置の指定は拒否する。
