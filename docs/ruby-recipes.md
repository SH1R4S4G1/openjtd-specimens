# 明示した読みのルビ試料（v0.7）

優先度3のルビを、範囲レシピ・マクロ台帳・JTD観測機能に追加しました。読みの自動生成には依存しません。短い横書き本文の制約は [範囲レシピ](range-recipes.md) と共通です。

```powershell
node bin/ichitaro-macro.mjs examples/ruby-ranges.json runs
node bin/ichitaro-macro.mjs examples/ruby-boundaries.json runs
node bin/ichitaro-catalog.mjs catalogs/my-ruby --run runs/<run-id>
node bin/ichitaro-observe.mjs run runs/<run-id>
```

## 操作

```json
{"target":"middle","type":"character","attribute":"ruby","mode":"set","reading":"たいしょう"}
```

| フィールド | 値・意味 | 既定値 |
|---|---|---|
| `mode` | `set` 新規設定、`modify` 既存ルビ変更、`clear` 解除 | 必須 |
| `reading` | 1～64文字の明示した読み。BMP、制御文字・結合文字なし | set/modifyで必須 |
| `evenly` | 0:均等なし、1:均等あり | 1 |
| `position` | 1:左、2:中央、3:右。均等なしの場合に適用 | 1 |
| `sizeMm` | ルビサイズ。ヘルプ記載単位はmm、アプリ側の受理範囲3～10 | 3 |
| `distanceMm` | 親文字との距離。ヘルプ記載単位はmm、アプリ側の受理範囲0～10 | 0 |
| `placement` | 1:上、2:下 | 1 |

解除ではreadingや装飾フィールドを指定しません。変更と解除には、同じ試料の同じ対象への先行する設定が必要です。変更では読みを必ず指定し、省略した装飾は表の既定値になります。部分的な更新とは異なるので、維持したい値も明示してください。

同じルビ属性の対象範囲が重なるレシピは拒否します。隣接する別範囲、1文字の対象は使用できます。フォント・スタイル・色の指定、縦書き、複数段落、複合条件の網羅試験はまだ対象外です。

## マクロと検証

- 新規設定・解除は範囲への `Ruby(1,...)` / `Ruby(0)`、変更は対象先頭に移動して `SetRuby(...)` を実行します。
- `GetCharacterInformation` のルビ有無を取得し、設定がある各文字で `GetRuby` と `GetRubyDecoration` を取得します。
- 読みの文字列一致、両getterの読みの一致、均等・サイズ・距離・上下配置の数値一致を確認します。均等なしの場合は左・中央・右の指定も照合します。
- 均等ありの場合、positionは適用対象外として `positionApplicable:false` を記録します。getterの返却値は保存しますが、その値を位置指定の効果の証明には使いません。
- 対象外の文字属性・文字情報・ルビの読みと装飾を操作前後で比較します。本文同一性、対象位置、保存前と再読込後の状態も確認します。
- 各操作段階の読み戻しは保存しますが、保存・再読込の証拠は試料の最終状態についてです。中間状態を個別に保存したことにはしません。

サイズ1を明示した呼び出しは実機で引数エラーになり、3・4は受理されて同じ値を読み戻せました。3～10はアプリ側の保守的な受理範囲で、一太郎の仕様上限・下限や全値域の実証ではありません。**サイズ・距離の確認はAPIの数値一致です。画面・印刷上の実寸は測定していません。** 省略時に返るNILを数値0として扱うこともしません。

ルビのない文字では存在フラグを確認し、ルビgetterを呼ばず、空の読みを観測スキーマに記録します。これは不存在時のgetterが空文字を返すことを実証した記録ではありません。

## 実機結果

一太郎2026で18試料が対象外検査と保存・再読込を通過しました。自動テスト118件も成功しています。

| レシピ | 試料数 | 時間 | run |
|---|---:|---:|---|
| `ruby-ranges.json` | 10 | 約58秒 | `2026-10-10T04-48-29-190Z-a9593c44` |
| `ruby-boundaries.json` | 8 | 約51秒 | `2026-10-10T04-50-04-440Z-26e18856` |

基本試料は設定・読み変更・解除・再設定、中央、サイズ4、距離0.5、下配置を含みます。境界試料は先頭、同文2回目、末尾、1文字、隣接するルビの片方だけの解除・変更を含みます。最後の変更試料では、複数の装飾値を同時に変更し、先行する隣接ルビが変わらないことを確認しました。

台帳: `catalogs/ruby-v07/index.html`。観測レポート: `observations/ruby-v07/index.html`。バイト差分は対応仮説の候補であり、形式上の意味の確定ではありません。

## 出典と次の対象

添付公開ヘルプ `Ruby:t26m0xo9`、`SetRuby:t26m06ih`、`GetRuby:t26m7n95`、`GetRubyDecoration:t26m22zy`、呼び出し例 `t26m6c4v` / `t26m6c4m` を参照しました。JTDの作成・保存は正規一太郎が行い、DLL解析やJTD書換えは行いません。

v0.7当時の次の対象は文字装飾・文字囲み罫線でした。後続版で[文字装飾](decoration-recipes.md)と[本文罫線・罫線表](keisen-recipes.md)を実装しました。最新の状態は [capabilities.json](../capabilities.json) を参照してください。

### 外部要求の省略との区別（2026-10-13）

上表は従来の内部Recipeでフィールドを省略した場合の既定値であり、互換性のため維持する。外部Sample Catalogでは、省略したルビ属性を内部Recipeの `null` へ変換し、Sprintの空引数として渡す。外部JSON自体に `null` を指定する契約ではない。内部で `null` と明示数値を区別することで、既存試料レシピの意味を変えずに外部要求の省略を一太郎へ委ねる。

サイズの空getter値は自動設定状態として保存し、具体的なmm値を検証したとは扱わない。その他の明示属性の照合、本文・範囲外検査、全getter状態の保存・再読込保持を続ける。詳細は [外部要求仕様](sample-request-spec.md) を参照。
