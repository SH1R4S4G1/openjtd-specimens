# 行列追加・削除／任意セル結合・分割の開発記録

ユーザーの目標は行・列の追加／削除と任意セル単位の結合・分割を、正規一太郎による保存・再読込検証まで含めて実装することです。以下は日付順の開発履歴です。各節の未実装・未検証という記載は、その時点の状態を表します。現行の対応状況は生成Capability表とマクロ台帳を参照してください。

## 2026-10-11：公開マクロの実機調査

文字入り2×2表（甲・乙／丙・丁）で確認しました。試験マクロは作業用文書だけを作り、終了時に閉じます。この段階のプローブは保存・再読込検証を含みません。

- 行挿入：通常行座標で始点を対象行の上罫線、終点を次の上罫線の1行手前に置き、`KeisenModifyLineMode(1,1)` と `KeisenModifyLine(2)`。2行高の空行が加わり、既存文字は下に移る。上境界を含む同じ2行を通常削除すると元へ戻る。
- 列挿入：半角座標で始点を対象列の左罫線、終点を右罫線の1桁手前に置き、`KeisenModifyColumnMode(1,2)` と `KeisenModifyColumn(2,1)`。4半角幅の空列が加わり、既存文字は右へ移る。同区間の通常削除で元へ戻る。
- 以前のコピー挿入試験は終点に次の境界を含めていたため、期待しない余分な区間を挿入していた。
- 左列だけの上下結合：横罫線の左セル区間を `Keisen(0)` で消す。隣の右列の境界は保持される。結合セルの `GetString(2)` は `甲`、空文字、`丙` の3要素。結合前の文字を物理行位置に保持する。
- 同じ部分罫線を引き直すと元の罫線と本文配置へ戻る。複数行文字の取得・証跡形式への対応が必要。

プローブ： [実行コード](../../tmp/probe-table-structure.mjs)、[行結果](../../tmp/structure-row.txt)、[列結果](../../tmp/structure-column.txt)、[結合結果](../../tmp/structure-merge.txt)。行・列は9×17のグリッドの右／下方向について期待する線分と一致を検査しました。[行列照合コード](../../tmp/check-structure-probes.mjs)、[部分結合照合コード](../../tmp/check-merge-probe.mjs)。製品の全8方向・属性・保存後検証はまだ必要です。

## 幾何モデル（実行経路への組み込み前）

## 2026-10-12：実行経路の接続と実機検証

[keisen-structured.mjs](../../src/keisen-structured.mjs)を実行validator・マクロ生成・読み戻しへ接続しました。`tableBand`、`cellMerge`、`cellSplit`を含む内部Recipeはこの経路を使います。通常の `table` / `tableText` / `tableAttribute` / `tableRule` を併用できます。外部Sample Catalogにはまだ公開していません。

検証証跡はversion 4です。全方向の罫線、セルIDと幾何、物理行ごとの文字、セル属性、文書全体の非空白文字を比較します。文字比較時の構造的空白は無視しますが、保存前後の生のgetter文字列は同一を要求します。新規行列は空セルを作り、削除した帯の文字だけを除きます。結合・分割は文字の物理位置を保持し、分割線が文字を横切る入力は拒否します。

### 観測マクロの小型化

[寸法指定の初回run](../../runs/2026-10-11T16-12-31-437Z-537addee/index.html)はbaselineと行列の追加・復元まで成功したが、最後の右下セル分割でタイムアウトした。最後のマクロは79,170行・約4.7MBで、結果ファイルと完了通知が生成されていなかった。一太郎のウィンドウ・プロセスが残っていないことと元の実行者の終了を確認し、所有者情報を保存したうえで該当ロックだけを除去した。PIDは後に無関係なEdgeプロセスに再利用されており、そのプロセスには触れていない。途中のロック検査を通らなかったrunは一太郎を起動せず終了している。

停止原因は断定していない。出力量に対して生成ソースが膨らむ問題を解消するため、公開言語仕様 `T36SPR/html/t26s3837.htm` のfor/nextを使い、観測グリッドを二重ループで巡回するようにした。観測範囲、方向、属性、結果キーと照合処理は変えていない。全172件の自動テストと契約checkを再実行して成功。失敗runへの再開・上書きは行わず、新規runで検証する。

[小型化後の6試料](../../runs/2026-10-12T00-07-50-655Z-37d9371a/index.html)はすべて保存・再読込と証跡ハッシュ検査に成功した。既定と異なる寸法での行列追加と削除による復元、文字入りの右下セルだけの2×2分割を確認した。右下セル分割のマクロは110,404バイトになり、当該試料の実行は25.470秒で完了した。この測定だけで先の停止原因を確定したとは扱わない。
